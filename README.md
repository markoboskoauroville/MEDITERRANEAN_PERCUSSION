# The Oldest Drum

**A Mantra field book on Mediterranean frame drumming.**

Live: https://markoboskoauroville.github.io/MEDITERRANEAN_PERCUSSION/
Plain text: [BOOK.md](BOOK.md)

The modern frame drum lineage — Glen Velez, Layne Redmond, Zohar Fresco, Yshai
Afterman — plus the instruments, the rhythm cycles written out to play, the
Sufi daf, a comparison with the Malinke djembe tradition, what South Indian
konnakol offers, and how to actually begin. Twelve chapters, thirteen plates.

## Declared interest

**Yshai Afterman is the author's teacher.** Chapter five says so in its first
line. Every claim in that chapter comes from his own published site or
biography and is linked so a reader can check it rather than trust the author.
If you edit this repository, keep the declaration and keep the links.
